Where Our Graduates Go

DePaul College Prep graduates enroll at colleges and universities across the country and around the world. Explore the map to see where recent classes have gone: hover a state for a summary, then click it to see every school with a flag.

Embedding the map

The map is delivered as a single self-contained file that the school uploads to its own website's file manager, then references from the College Planning page. No outside hosting is involved. Full instructions, including notes for Finalsite and Blackbaud, are in docs/embedding.md.

Option A · Script tag

Upload dist/dcp-college-map.bundle.js, then add this where the map should appear. Best when the page editor accepts raw HTML.

<div data-dcp-college-map></div>
<script src="YOUR-FILE-URL/dcp-college-map.bundle.js" defer></script>

Option B · iframe

Upload dist/dcp-college-map.html and embed it exactly like the current Google My Maps iframe.

<iframe src="YOUR-FILE-URL/dcp-college-map.html"
  title="Where DePaul Prep graduates go to college"
  width="100%" height="780" style="border:0;max-width:100%"
  loading="lazy"></iframe>

Keeping it current

Each year, export the matriculation report, drop it in data/raw/, and run scripts/build_data.py. The script aggregates the report to per-school counts (no student names or IDs are ever published), looks up each school's location and logo, and regenerates the files in dist/. Upload those over the previous copies and the embedded map is updated. See docs/refreshing-data.md.
